# fsr_Kaggle-Competition-GDGOC-2025
"Customer Churn Prediction Challenge" Task ini membangun ML yang mampu memprediksi seorang pelanggan akan keluar dari bank atau tetap menjadi pelanggan aktif.  Tujuannya adalah untuk memprediksi variabel target Exited dalam dataset uji. Variabel ini menunjukkan apakah pelanggan telah keluar dari bank (1) atau tetap menjadi pelanggan aktif (0).
Dengan F1-score: 0.9967637540453075
